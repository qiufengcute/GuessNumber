# GuessNumber / 猜数字

**A simple number-guessing minigame. Guess the random number in the GUI—how many tries will it take? / 一个简单的猜数字小游戏。在GUI中猜随机数字——试试几次能猜中？**

---

## How to Play / 玩法说明

**Getting Started / 开始游戏:**
![Guess GUI](https://cdn.modrinth.com/data/cached_images/ab2c7144bf2a4c9517a3953fbcf788a15a06e228.png)
- Type **/startguess** to open the guess number GUI / 输入 **/startguess** 打开猜数字界面

**Game Rules / 游戏规则:**
- A random number between 1-100 is generated / 系统会随机生成一个 1-100 的数字
- Enter your guess in the GUI and click confirm / 在界面中输入你的猜测并点击确认
- Get instant feedback: "Too high!" or "Too low!" / 立即得到反馈："大了！"或"小了！"
- Keep guessing until you find the correct number / 继续猜测直到猜中
- The game tracks how many attempts you took / 游戏会记录你猜了多少次

**Features / 特色:**
- Intuitive GUI interface / 直观的图形界面
- Instant feedback on each guess / 每次猜测即时反馈
- Attempt counter / 猜题次数统计
- Perfect for server mini-games or solo fun / 适合服务器小游戏或单人娱乐
